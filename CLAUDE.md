# TG Empires — инструкции для Claude

Пошаговая мультиплеерная стратегия в Telegram Mini App: бот на grammY + сервер Express/Socket.IO + клиент React,
общие правила в `shared/`.

## Навигация по коду — ОБЯЗАТЕЛЬНО

Перед любой задачей открой **[docs/MAP.md](docs/MAP.md)** — карта «задача → файл:строки».
Ищи нужный участок там и читай только его, а не весь код. Подробности по разделам:

- [docs/overview.md](docs/overview.md) — что делает бот, архитектура, правила игры
- [docs/server.md](docs/server.md) — сервер, бот, авторизация, комнаты, socket-протокол
- [docs/engine.md](docs/engine.md) — игровой движок и баланс (`shared/`)
- [docs/client.md](docs/client.md) — интерфейс Mini App (`client/`)
- [docs/deploy.md](docs/deploy.md) — прод-сервер, env, сборка, тесты

После изменений, сдвинувших функции/блоки, обнови номера строк в `docs/MAP.md` и профильном документе.

## Стиль ответов — ОБЯЗАТЕЛЬНО

- Коротко, без воды, на русском. Никаких промежуточных комментариев и пересказа процесса.
- В конце — только итог в виде того, что теперь умеет бот/игра, с точки зрения игрока.
  Не «добавил функцию удара» / «исправил функцию ходьбы», а «теперь можно атаковать соседнюю клетку»,
  «теперь юниты ходят на 2 клетки по дороге».

## Ключевые факты

- Правила меняются только в `shared/src/engine.ts` и данных (`config.ts`, `units.ts`, `eras.ts`); сервер generic.
- Состояние партий только в памяти (`server/src/rooms.ts`) — рестарт сервиса стирает игры.
- Прод: `ssh peepuy`, `/root/tg-empires`, `systemctl restart tg-empires`.
- Проверка правил: `npm run smoke`, типы: `npm run typecheck`.
