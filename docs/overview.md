# Обзор: что делает бот

**TG Empires** — пошаговая мультиплеерная стратегия на 2–4 игрока внутри Telegram Mini App.
Telegram-бот (`@...`, grammY) выдаёт кнопку «Играть» и ссылки-приглашения в комнаты;
сама игра — веб-приложение (React), которое открывается внутри Telegram.

## Архитектура

```
Telegram-чат ──/newgame, /join──▶ bot.ts (grammY, long polling)
      │                              │ createRoom / getRoom
      │ кнопка WebApp                ▼
      ▼                          rooms.ts  (Map<code, GameState> в памяти)
Mini App (client/, React) ◀──Socket.IO──▶ server/src/index.ts
      │                                      │ applyAction / applyLobbyAction / startGame
      └── импортирует @tge/shared ──────────▶ shared/src/engine.ts (правила)
```

- **Сервер авторитетный**: состояние партии (`GameState`) живёт только на сервере, клиент шлёт действия.
- **shared/** — общий TypeScript-пакет `@tge/shared`: правила используются и сервером (для применения),
  и клиентом (для подсказок: досягаемые клетки, прогноз боя, стоимость).
- Состояние **не сохраняется** в БД — рестарт сервиса убивает все партии.
- Каждому игроку уходит **маскированная копия** состояния (туман войны) — `vision.ts maskStateFor`.

## Поток одного действия

1. Клиент: `GameScreen` → `act(action)` (`App.tsx:122`) → `request(socket, 'game:action', {action})`.
2. Сервер: `index.ts:139` → `applyAction(state, actor, action)` (мутирует state) → `autoEndTurnIfExhausted`.
3. Ответ-ack автору: `{ok, state: viewOf(...), fx}`; остальным — `update` через `pushState` (каждому своя маска).
4. Клиент: `applyWithFx` ставит состояние и проигрывает анимацию `fx` (`MapBoard`).

## Поток входа в игру

1. `/newgame` в боте → `createRoom(hostId)` → ответ с кодом комнаты и кнопкой WebApp `?room=КОД`,
   плюс ссылка `https://t.me/<bot>?start=КОД` для друзей.
2. Друг жмёт ссылку → `/start КОД` → бот проверяет комнату, даёт кнопку.
3. Mini App: сокет авторизуется по `initData` (`auth.ts`), клиент берёт код из `start_param` или `?room=`
   (`telegram.ts roomCodeFromEnvironment`) и шлёт `room:join`.
4. В лобби хост/админы меняют настройки и рельеф, хост жмёт «Начать» → `game:start`.
5. Из меню можно также создать комнату (`room:create`) или партию «сам с собой» (`room:solo`, hotseat).

## Правила игры (коротко)

- Гекс-карта (odd-r, pointy-top) 8/10/12/14 клеток; горы и море непроходимы.
- Столица (★, с крепостью) в углу + соседние клетки. Старт: 60🪙 40🌾 20🔩, 6 пехоты (настраивается).
- **Начало хода** (`beginTurn`): достраиваются постройки → доход с клеток/построек/столицы (×техи экономики)
  → содержание армии (еда по `upkeep` рода войск: пехота 1–1.6, конница 2–3; нехватка — дезертирство 15%) → восстановление хода войск → каре «съедает» действия.
- **Действия за ход**: `actionsPerTurn` (по умолч. 5) + уровень логистики. Тратят действие: найм, стройка,
  техи, командир, залп, каре, начало марша стека (продолжение марша того же стека — бесплатно).
- **Войска**: 12 родов = 4 класса (пехота, конница, лучники, конные лучники) × 3 тира. Классы бьют друг друга
  по кругу: конница > лучники > пехота > конница. Каждый стек имеет запас хода (`movesLeft`) и залп (`shotsLeft`).
- **Бой**: сила × техи × местность × постройки × командир × случайность ±15%. Проигравший может
  **бежать** (routed) на 1–2 хода — неуправляем, ослаблен.
- **Набег** (charge): конница бьёт с 2 клеток, ×1.2, тратит 2 хода.
- **Залп**: лучники/мушкеты/артиллерия стреляют на 2+ клетки; после марша — слабее.
- **Совместный удар**: свои соседние стеки могут бить вместе с атакующим.
- **Командиры**: Воевода (+атака), Маршал (+защита, реже бежит), Рейд-капитан (+ход, +обзор).
- **Эпохи**: античность / средневековье / наполеоника — меняют названия и часть статов;
  в наполеонике есть **каре** (пехота против конницы, обороне предлагают выбор при атаке).
- **Туман войны**: видно свои клетки и в радиусе обзора (3) с учётом линии видимости; чужие постройки запоминаются.
- **Победа**: взятие столицы уничтожает державу (земли — захватчику). Последний выживший побеждает,
  иначе после `maxRounds` (по умолч. 30) — по очкам (`scoreOf`).

## Дополнения к правилам

Случайные события (у каждого свои, выключаются в лобби), дипломатия (перемирие, союз, общая победа), таймер хода (без лимита / 2 / 5 мин / 1 ч / 24 ч), ИИ-соперники трёх уровней, реванш, обучение.
