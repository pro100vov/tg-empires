# TG Empires

Пошаговая многопользовательская стратегия внутри Telegram Mini App: 2–4 игрока
развивают державу, строят экономику, изучают технологии, нанимают войска и
захватывают территории соперников. Ходы идут по очереди, состояние партии
считает сервер — клиент только отображает и отправляет действия.

## Структура

```
shared/   игровые правила: карта, экономика, бой, технологии (общий код клиента и сервера)
server/   Express + Socket.IO (авторитетный сервер) + бот на grammY
client/   React + Vite, интерфейс мини-приложения
```

## Правила

* Карта — квадратная сетка, размер зависит от числа игроков. Горы и море непроходимы.
* У каждого игрока столица (★) и стартовая территория в своём углу карты.
* В начале хода приходит доход со всех своих клетек и построек, затем списывается
  содержание армии (1 еда на 2 отряда). Нехватка еды — дезертирство 15%.
* За ход даётся 3 действия (+1 за уровень логистики). Действие — это найм,
  постройка, изучение технологии или перемещение отряда на соседнюю клетку.
* Перемещение во вражескую клетку с войсками — бой. Исход считает сервер: сила
  сторон умножается на технологии, местность и постройки, плюс случайность ±15%.
* Захват столицы уничтожает державу, её земли переходят завоевателю.
* Партия заканчивается, когда остаётся один игрок, либо после 30 раундов — тогда
  побеждает тот, у кого больше очков за земли, постройки, армию и технологии.

## Быстрый старт

```bash
npm install
cp .env.example .env   # на Windows: Copy-Item .env.example .env
npm run dev
```

Откроется клиент на `http://localhost:5173` и сервер на `http://localhost:3000`.

При `DEV_MODE=1` вход работает без подписи Telegram — удобно тестировать в
обычном браузере. Двух игроков можно открыть в соседних вкладках:

```
http://localhost:5173/?dev=alice
http://localhost:5173/?dev=bob&room=КОД
```

Проверить правила без интерфейса (экономика, лимит действий, бой, падение
державы, голод):

```bash
npm run smoke
npm run typecheck
```

## Подключение к Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather), скопируйте токен в `BOT_TOKEN`.
2. Поднимите https-туннель к клиенту (Telegram принимает только https):

   ```bash
   cloudflared tunnel --url http://localhost:5173
   ```

   Полученный адрес запишите в `WEBAPP_URL`.
3. В BotFather выполните `/newapp`, привяжите Mini App к боту, укажите тот же
   URL и короткое имя — его же положите в `WEBAPP_SHORT_NAME`.
4. Перезапустите `npm run dev`. В боте станут доступны команды:
   * `/newgame` — создать комнату и получить ссылку-приглашение;
   * `/join КОД` — присоединиться к существующей комнате;
   * `/help` — правила.

Ссылка-приглашение вида `https://t.me/<бот>/<app>?startapp=КОД` открывает мини-
приложение сразу в нужной комнате: друг переходит по ней и попадает в лобби.

Для боевого развёртывания соберите клиент (`npm run build`) и запустите сервер
(`npm start`) — он раздаёт готовую сборку из `client/dist`, так что хватит одного
https-домена на всё приложение.

## Что стоит добавить дальше

* Сохранение партий в базу (сейчас комнаты живут в памяти процесса).
* Уведомления в чат бота о том, что подошёл ваш ход.
* Дипломатию, морские перевозки, разные типы юнитов.
